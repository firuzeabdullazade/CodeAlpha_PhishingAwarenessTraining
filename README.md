# CodeAlpha - Phishing Awareness Training

This project was completed as part of the CodeAlpha Cyber Security Internship.

## Project Overview

The purpose of this project is to raise awareness about phishing attacks
and help users recognize common phishing techniques.

## Topics Covered

- Phishing attacks
- Social engineering
- Phishing emails
- Fake websites
- Suspicious URLs
- Prevention techniques
- Incident response
- Interactive quiz

## Learning Outcome

This project helped me understand how phishing attacks exploit human
behavior and how users can identify and respond to suspicious messages
and websites.
